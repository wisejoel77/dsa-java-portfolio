## 📝 Repository Structure Note

This repository is organized primarily for **readability, learning progression, and easy exploration on GitHub**, rather than as a single unified Java application.

Most folders contain independent DSA implementations, examples, practice problems, or algorithmic exercises focused on specific data structures and problem-solving techniques. Since these programs may be developed independently as part of my learning process, **package declarations and directory structures may not always follow one consistent project-wide structure**.

If you download the repository and open it in IntelliJ IDEA, some individual programs may need to be opened or configured separately, particularly when their Java package declarations do not directly match the repository's visual folder structure.

This does not affect the purpose of the repository. The main goal is to document my **DSA learning journey and progression**, while keeping each concept, implementation, and problem easy to understand and explore.

For problems or implementations involving multiple classes, the files within their respective folders are intended to be used together.
